# TypeFlow

TypeFlow is a typing test application built using Node.js, Express, and EJS. It allows users to test their typing speed and accuracy by typing a randomly generated paragraph within a specified time limit. 

## How to Use?
1. Download and extract zip or 
2. <pre><../>$ git clone git@github.com:Dhruvjalan/TypeFlow.git  </pre>  in GitBash
3. Open the folder <pre>../TypeFlow</pre> in the terminal/Powershell
4. <pre><../>cd .\TypeFlow\</pre>
5. <pre><../TypeFlow> npm i</pre>
6. <pre><../TypeFlow> nodemon app </pre>

## Setting Up the Test
Setting up the test requires you to specify the below parameters: 

1. Level: 
    - Beginner
    - Intermediate
    - Advanced
    - Pro
2. Time Limit: 30s, 60s, 120s, 180s
3. Give Test only from the keys in:
    - Overall keyboard
    - Top Row
    - Home Row
    - Bottom Row
    - Punctuations and Numbers
4. Emphasis on:
    - overall keyboard equally
    - Top Row
    - Home Row
    - Bottom Row
    - Punctuations and Numbers

5. Paragraph Type:
    - Random
    - Real Life
